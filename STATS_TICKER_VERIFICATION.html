🧩 الهيكل الجديد في App.tsx

<div className="appShell">
  <header className="appHeader">
    <ModernTopHeader />
  </header>

    {/* محتوى الصفحات */}
  </main>

  <!-- الفوتر = شريط الإحصائيات -->

🎨 CSS المطبق (100% حسب المواصفات)

:root {
  --header-h: 72px;
  --footer-h: 56px; /* شريط الإحصائيات */
}

.appShell {
  position: fixed;
  inset: 0;
  height: 100svh; /* ثابت على iPhone */
}

.appHeader {
  position: fixed;
  top: 0;
  height: var(--header-h);
}

.appFooter {
  position: fixed;
  bottom: 0;
  height: var(--footer-h);
}

.appMain {
  position: absolute;
  top: var(--header-h);
  bottom: calc(var(--footer-h) + env(safe-area-inset-bottom));
  overflow-y: auto;
}

🧪 دليل الاختبار السريع

1. افتح المنصة العامة على activeModule === 'public'، الفوتر يظهر تلقائياً
2. راقب شريط الإحصائيات يجب أن يكون ثابتاً في الأسفل ويتحرك محتواه بسلاسة
3. جرّب التمرير تمرير بطيء، قوي، متقطع، تغيير اتجاه - الفوتر يبقى ثابت
4. تحقق من المحتوى الأنشطة تتحرك أفقياً، الأيقونات والنصوص واضحة
