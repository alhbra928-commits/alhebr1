❌ المشكلة:
───────────────────────────────────────────────────
  mzad1.com لا يفتح!
  يحول إلى bolt.host
  loop redirect (حلقة لا نهائية)

السبب:
  الدومين mzad1.com مربوط بـ Bolt

  يجب ربطه بـ Netlify


✅ الحل (4 خطوات):
═══════════════════════════════════════════════════

الخطوة 1: انشر على Netlify
─────────────────────────────────────
  1. افتح: https://app.netlify.com
  2. سجل دخول
  3. اسحب مجلد dist/
  4. أفلته في الصفحة
  5. انتظر 30-60 ثانية
  6. ✅ احصل على رابط مثل:
     https://palm-olive-123456.netlify.app

  ⚠️ مهم: تأكد أن الرابط يعمل!


الخطوة 2: احذف السجل القديم من Hostinger
─────────────────────────────────────
  1. افتح: https://hpanel.hostinger.com
  2. اذهب: Domains → mzad1.com
  3. اضغط: DNS / Name Servers
  4. اضغط: Manage DNS records
  5. ابحث عن أي سجل يحتوي على:
     ❌ bolt.host
     ❌ bolt.new
  6. احذفه! (🗑️ سلة المهملات)
  7. ✅ تأكد من اختفائه


الخطوة 3: أضف السجلات الجديدة
─────────────────────────────────────
  في نفس صفحة DNS Records:

  السجل الأول (A Record):
  ─────────────────────────
    Type: A
    Name: @ (أو اترك فارغاً)
    Points to: 75.2.60.5
    TTL: Automatic

  السجل الثاني (CNAME):
  ─────────────────────────
    Type: CNAME
    Name: www
    Points to: palm-olive-123456.netlify.app
    TTL: Automatic

  ⚠️ مهم: استبدل "palm-olive-123456"
           برابط موقعك من Netlify!

  بعد الإضافة:
    اضغط Save
    ✅ تأكد من ظهور السجلين


الخطوة 4: أضف الدومين في Netlify
─────────────────────────────────────
  1. في Netlify Dashboard
  2. اضغط: Domain settings
  3. اضغط: Add custom domain
  4. اكتب: mzad1.com
  5. اضغط: Verify
  6. ✅ يجب أن يظهر: Domain verified


⏰ متى سيعمل الموقع؟
═══════════════════════════════════════════════════

  بعد 0 دقيقة:
    → DNS القديم مازال محفوظ
    → الموقع لا يعمل (طبيعي!)

  بعد 5-15 دقيقة:
    → DNS بدأ ينتشر
    → بعض الأجهزة تشاهد الموقع

  بعد 30-60 دقيقة:
    → انتشار جيد
    → معظم الناس يشاهدون الموقع

  بعد 2-4 ساعات:
    → انتشار ممتاز
    → تقريباً الجميع يشاهدون الموقع

  بعد 24-48 ساعة:
    → انتشار كامل 100%
    → الجميع بدون مشاكل


🧪 كيف تختبر؟
═══════════════════════════════════════════════════

  الطريقة 1: المتصفح
  ─────────────────────
    1. امسح Cache (Ctrl + Shift + Delete)
    2. افتح: https://mzad1.com
    3. إذا فتح → تم! ✅
    4. إذا مازال loop → انتظر قليلاً

  الطريقة 2: nslookup
  ─────────────────────
    في Terminal أو CMD:
      nslookup mzad1.com

    يجب أن ترى:
      Address: 75.2.60.5

  الطريقة 3: Online
  ─────────────────────
    افتح: https://dnschecker.org
    اكتب: mzad1.com
    شاهد الانتشار حول العالم


💡 نصائح مهمة:
═══════════════════════════════════════════════════

  • امسح Cache المتصفح دائماً
  • جرب في Incognito Mode
  • جرب من جهاز آخر أو شبكة أخرى
  • لا تقلق إذا لم يعمل فوراً (انتظر 30 دقيقة)
