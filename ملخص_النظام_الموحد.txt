المعايير التقنية:
═══════════════════════════════════════════════════════

Animation واحد:
   @keyframes marquee-scroll {
     0%   { transform: translateX(0); }
     100% { transform: translateX(-50%); }
   }

Track موحد:
   animation: marquee-scroll 14s linear infinite;

Gap موحد:
   gap: 10px;
   justify-content: flex-start;

Auto-Fill:
   const minRepetitions = 4;
   → يُكرر المحتوى 4 مرات تلقائياً
   → يغطي 3× عرض الشاشة
   → يمنع الفراغ بين أول وآخر عنصر

خطوات الاختبار:
═══════════════════════════════════════════════════════

1. امسح الكاش تماماً
   Settings → Safari → Clear History and Website Data

2. أغلق Safari تماماً
   Double-tap Home → Swipe up Safari
   انتظر 5 ثواني

3. افتح Safari من جديد
   افتح المنصة → انتظر التحميل الكامل

4. راقب الشريط
   • يجب أن يتحرك بسلاسة
   • بدون فراغات
   • نفس المحتوى على الجوال والكمبيوتر
