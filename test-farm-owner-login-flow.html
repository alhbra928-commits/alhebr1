🔄 التدفق المتوقع للمستخدم الجديد

الخطوة 1: إدخال رقم الجوال

• المستخدم يدخل رقم جواله (مثال: 0501234567)

• النظام يتحقق من وجود الحساب

const { exists } = await farmOwnerService.checkAccount(cleanMobile);

الخطوة 2: طلب الاسم (للمستخدم الجديد فقط)

إذا كان الحساب غير موجود:

• يتم الانتقال إلى خطوة إدخال الاسم

if (!exists) { setIsNewAccount(true); setStep('name'); // ← الانتقال لخطوة الاسم }

• يظهر للمستخدم:

- عنوان: 👤 الاسم الكامل

- رسالة: مرحباً بك في منصة الحبر

- حقل إدخال: مثال: أحمد محمد العلي

- زر: ✓ إنشاء حسابي

الخطوة 3: إنشاء الحساب مع الاسم

• المستخدم يدخل اسمه الكامل

• عند الضغط على "إنشاء حسابي":

const result = await farmOwnerService.directLoginWithName( mobileNumber, fullName.trim() );

• يتم:

1. إنشاء الحساب

2. حفظ الاسم في قاعدة البيانات

3. تسجيل الدخول تلقائياً

الخطوة 4: الدخول إلى اللوحة

• يظهر الترحيب: مرحباً أحمد محمد

• في الهيدر: أحمد محمد - 0501234567

🔄 التدفق للمستخدم الحالي

إذا كان الحساب موجود مسبقاً

• لا يتم طلب الاسم

• يتم إرسال OTP مباشرة

if (exists) { // إرسال OTP const result = await farmOwnerService.sendOTP(cleanMobile); setStep('otp'); // ← الانتقال لخطوة OTP }

🧪 اختبار يدوي

لاختبار التطبيق:

1. افتح صفحة تسجيل الدخول لصاحب المزرعة

2. أدخل رقم جوال جديد (لم يُستخدم من قبل)

3. يجب أن تظهر صفحة طلب الاسم الكامل

4. أدخل الاسم واضغط "إنشاء حسابي"

5. تحقق من ظهور الاسم في الترحيب والهيدر

🚀 فتح صفحة تسجيل الدخول

💻 الكود الفعلي المُطبق

useState للخطوات:

const [step, setStep] = useState<'mobile' | 'name' | 'otp'>('mobile'); const [fullName, setFullName] = useState('');

منطق التحقق من الحساب:

const { exists } = await farmOwnerService.checkAccount(cleanMobile); if (!exists) { // حساب جديد - اطلب الاسم setIsNewAccount(true); setStep('name'); } else { // حساب موجود - أرسل OTP const result = await farmOwnerService.sendOTP(cleanMobile); setStep('otp'); }

دالة حفظ الاسم:

async directLoginWithName(mobileNumber: string, fullName: string) { // إنشاء الحساب const { data, error } = await supabase.rpc('farm_owner_login_or_create', { p_mobile_number: mobileNumber }); // تحديث الاسم await supabase .from('farm_owner_profiles') .update({ full_name: fullName }) .eq('id', data.profile_id); }
