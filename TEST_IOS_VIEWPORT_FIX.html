💻 الكود المضاف

1️⃣ ملف iosViewportFix.ts:

export function applyIOSViewportFix() { const vv = window.visualViewport; const setVars = () => { const h = vv ? vv.height : window.innerHeight; const top = vv?.offsetTop ?? 0; document.documentElement.style.setProperty("--vvh", `${h}px`); document.documentElement.style.setProperty("--vvtop", `${top}px`); }; setVars(); if (vv) { vv.addEventListener("resize", setVars); vv.addEventListener("scroll", setVars); } window.addEventListener("orientationchange", setVars); window.addEventListener("resize", setVars); console.log('[iOS Viewport Fix] Initialized ✓'); }

2️⃣ التعديلات في CSS:

/* قبل ❌ */ .appShell { height: 100svh; } /* بعد ✅ */ .appShell { height: var(--vvh, 100svh); } /* الهيدر */ .appHeader { top: var(--vvtop, 0); } /* حماية overscroll */ .appMain { overscroll-behavior: contain; }

🧪 كيف تختبر على iPhone

الخطوات:

  1. افتح المنصة على iPhone باستخدام Safari
  2. اذهب إلى المنصة العامة (الصفحة الرئيسية)
  3. اختبار التمرير:
    • اسحب فوق/تحت بسرعة (10-20 مرة)
    • راقب الهيدر والفوتر
    • تحقق: لا يختفي، لا يقفز ✓
  4. اختبار التدوير:
    • اقلب الشاشة من Portrait إلى Landscape
    • تحقق: الهيدر والفوتر يتكيفان بسلاسة ✓
  5. اختبار الزووم:
    • zoom in/out (اضغط بإصبعين)
    • تحقق: لا تشوهات، كل شيء ثابت ✓
  6. افتح Console:
    • على Mac: Safari → Develop → [iPhone] → Console
    • تحقق من ظهور: [iOS Viewport Fix] Initialized ✓
    • راقب المعلومات عند التمرير
