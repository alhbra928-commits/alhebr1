2جرّب التمرير القوي

جرّب جميع أنواع التمرير على iPhone:

  • تمرير بطيء للأسفل/للأعلى
  • تمرير قوي/سريع جداً
  • تمرير متقطع (توقف ثم تمرير)
  • تغيير الاتجاه بسرعة
  • تمرير حتى النهاية

3معيار النجاح

✅ يجب أن يحدث:

  • الخط الأحمر ثابت في الأعلى دائماً
  • الخط الأزرق ثابت في الأسفل دائماً
  • معاً في نفس الوقت - لا تبادل
  • المحتوى فقط يتحرك
  • لا قفز أو اهتزاز
  • لا white flash

🔍 إذا فيه مشكلة - كيف تشخصها؟

❌ السيناريو 1: الخط الأحمر/الأزرق يختفي تماماً
المعنى: العنصر يخرج من الشاشة
السبب: ارتفاع خاطئ أو تموضع خاطئ
الحل: استخدام 100svh بدلاً من 100dvh (✓ تم تطبيقه)
⚠️ السيناريو 2: الخط موجود لكن المحتوى داخله يختفي
المعنى: CSS داخل المكوّن يخفي المحتوى
السبب: opacity: 0 أو transform خاطئ
الحل: تفتيش ModernTopHeader.tsx و BottomNavigationBar.tsx
✅ السيناريو 3: كل شيء ثابت ومرئي
المعنى: الحل نجح 100%!
الخطوة التالية: احذف Debug Borders من index.css

🔧 CSS المطبق:

.appShell {
  position: fixed; /* ← مقفول على الشاشة */
  inset: 0; /* ← يغطي كل الشاشة */
  display: grid;
  grid-template-rows: auto 1fr auto;
  height: 100svh; /* ← ارتفاع ثابت لا يتغير */
  width: 100%;
}

.appMain {
  overflow-y: auto;
  -webkit-overflow-scrolling: touch;
  overscroll-behavior: contain; /* ← حدود التمرير */
}

.appHeader, .appFooter {
  flex: 0 0 auto; /* ← لا يتمدد/ينكمش */
  transform: translateZ(0); /* ← طبقة GPU منفصلة */
  z-index: 10;
}

🎯 لماذا 100svh أفضل من 100dvh؟

عند التمرير في Safari:
❌ 100dvh (Dynamic):

• شريط Safari يختفي
• الارتفاع يتغير من 812px إلى 890px
• إعادة حساب التخطيط
• قفزات وقد يخرج عنصر

✅ 100svh (Small):

• الارتفاع ثابت (812px دائماً)
• لا تغيير = لا إعادة حساب
• ثبات مطلق
