  • الهيدر يبدأ من top: 0
  • لا يوجد padding-top للـ safe area

📱 التطبيق في الكود

1. الـ Container:

style={isMobile ? { paddingTop: 'env(safe-area-inset-top)', paddingBottom: 'env(safe-area-inset-bottom)', paddingLeft: 'env(safe-area-inset-left)', paddingRight: 'env(safe-area-inset-right)' } : undefined}

2. الـ Header:

style={{ background: 'linear-gradient(135deg, #10b981 0%, #059669 100%)', ...(isMobile ? { paddingTop: 'max(1rem, env(safe-area-inset-top))', minHeight: '64px' } : {}) }}

3. الـ Viewport Meta:

<meta name="viewport" content="width=device-width, initial-scale=1.0, viewport-fit=cover" />

ملاحظة: viewport-fit=cover مطلوب حتى يعمل env(safe-area-inset-*)
