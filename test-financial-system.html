📊 حالة الـ Triggers المالية

✅ إنشاء البطاقة المالية

Trigger: trigger_create_farm_finance_card

Table: farms

الوظيفة: ينشئ بطاقة مالية ذكية تلقائياً عند إضافة مزرعة جديدة

✅ تحديث المبلغ التسويقي

Trigger: trigger_update_marketing_amount

Table: reservations

الوظيفة: يحدّث المبلغ التسويقي تلقائياً عند إنشاء أو تحديث حجز

✅ حساب المبالغ المالية

Trigger: trigger_calculate_farm_finances

Table: smart_farm_finances

الوظيفة: يحسب التغطية والأرباح واستقطاع الخير تلقائياً

🔄 سير العمل التلقائي

1️⃣ عند إنشاء مزرعة جديدة

يتم استدعاء trigger_create_farm_finance_card تلقائياً
→ ينشئ بطاقة مالية ذكية
→ يربطها بالمزرعة والمالك
→ يولّد باركود مالي فريد

2️⃣ عند إنشاء حجز وإكمال الدفع

يتم استدعاء trigger_update_marketing_amount تلقائياً
→ يضيف المبلغ إلى marketing_amount
→ يحدّث عدد المستثمرين والأشجار المباعة
→ يسجل المعاملة في السجل المالي

3️⃣ حساب المبالغ المالية

يتم استدعاء trigger_calculate_farm_finances تلقائياً
→ يحسب نسبة التغطية: (marketing / actual) * 100
→ يحسب المتبقي: actual - marketing
→ يحسب الربح: marketing - actual (إذا كان موجباً)
→ يستقطع 25% للخير من الربح
→ يحسب صافي الربح للمنصة

4️⃣ عند الوصول لـ 100% تغطية

يقوم trigger_calculate_farm_finances تلقائياً بـ:
→ تسجيل دفعة كاملة لصاحب المزرعة
→ استقطاع 25% من الربح لمحفظة الخير
→ تسجيل صافي الربح للمنصة
→ تغيير حالة المزرعة إلى completed
