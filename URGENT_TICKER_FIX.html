التشخيص الشامل والإصلاح الفوري

⚠️ المشكلة:

الشريط موجود لكن فارغ من الإعلانات ولا يستجيب مع الإعدادات

🔍 خطوات التشخيص الفوري

1
احذف Cache كاملاً
Windows/Linux: Ctrl + Shift + Delete
Mac: Cmd + Shift + Delete
اختر: All time → Delete everything
2
Hard Reload
Windows/Linux: Ctrl + Shift + R
Mac: Cmd + Shift + R
أو: افتح DevTools → اضغط مع الاستمرار على زر Reload → اختر "Empty Cache and Hard Reload"
3
افتح Console قبل أي شيء
اضغط F12 أو Ctrl + Shift + I
اذهب لتبويب Console
⚠️ مهم جداً: Console يجب أن يكون مفتوحاً قبل تحميل الصفحة
4
افتح المنصة
اذهب إلى http://localhost:5173/
أو افتح المنصة المنشورة
5
راقب Console بعناية
يجب أن ترى رسائل مفصلة جداً عن حالة الشريط
اقرأ كل رسالة بعناية وحدد المشكلة

الحل:

افتح Supabase SQL Editor ونفذ هذا:

-- 1. تحقق من عدد الأنشطة المحاكاة SELECT COUNT(*) FROM simulated_activities WHERE is_active = true; -- 2. إذا كانت النتيجة 0 أو أقل من 10، أضف أنشطة INSERT INTO simulated_activities (template_ar, icon, weight, is_active) VALUES ('تم حجز 3 أشجار نخيل في منطقة الأحساء', '🌴', 20, true), ('انضم مستثمر جديد من الرياض للمنصة', '👤', 15, true), ('ارتفاع الطلب على أشجار الزيتون بنسبة 25%', '📈', 25, true), ('تم إصدار 5 شهادات تملك اليوم', '📜', 18, true), ('مزرعة جديدة تمت إضافتها في الخرج', '🏡', 12, true), ('تم توزيع أرباح بقيمة 50,000 ريال', '💰', 22, true), ('تسجيل 10 حجوزات جديدة خلال الساعة الأخيرة', '🎯', 16, true), ('افتتاح مزرعة جديدة للاستثمار', '🌟', 19, true), ('نجاح موسم الحصاد لمزرعة الرياض', '🎉', 14, true), ('تحديث أسعار الأشجار حسب السوق', '📊', 13, true); -- 3. تحقق من الإعدادات SELECT * FROM activity_ticker_settings; -- 4. إذا كانت simulation_enabled = false، فعّلها UPDATE activity_ticker_settings SET simulation_enabled = true, real_enabled = true, mode = 'hybrid' WHERE id IS NOT NULL; -- 5. أضف نشاط يدوي للاختبار SELECT create_manual_activity( 'test', '✅ النظام يعمل الآن بنجاح', 'System working', '✅', 10 );

بعد تنفيذ الاستعلامات:
✅ أعد تحميل الصفحة (Ctrl + Shift + R)
✅ راقب Console مرة أخرى
✅ يجب أن يعمل الشريط الآن

📊 استعلام تشخيصي شامل

نفذ هذا في Supabase لمعرفة الوضع الكامل:

SELECT 'Settings Count' as metric, COUNT(*)::text as value FROM activity_ticker_settings UNION ALL SELECT 'Real Activities (Visible)', COUNT(*)::text FROM platform_activities WHERE is_visible = true UNION ALL SELECT 'Simulated Activities (Active)', COUNT(*)::text FROM simulated_activities WHERE is_active = true UNION ALL SELECT 'Settings Mode', mode FROM activity_ticker_settings LIMIT 1 UNION ALL SELECT 'Simulation Enabled', CASE WHEN simulation_enabled THEN 'YES' ELSE 'NO' END FROM activity_ticker_settings LIMIT 1 UNION ALL SELECT 'Real Enabled', CASE WHEN real_enabled THEN 'YES' ELSE 'NO' END FROM activity_ticker_settings LIMIT 1;

النتيجة المتوقعة:

Metric Value
Settings Count 1
Real Activities 2+
Simulated Activities 10+
Mode hybrid
Simulation Enabled YES
Real Enabled YES
