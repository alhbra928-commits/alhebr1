═══════════════════════════════════════════════════════════════════
⚡ الحل السريع - 3 خطوات (5 دقائق)
═══════════════════════════════════════════════════════════════════

الخطوة 1️⃣: امسح CDN Cache
━━━━━━━━━━━━━━━━━━━━━━━━━━━━

إذا كنت تستخدم Netlify:
  1. اذهب إلى: https://app.netlify.com
  2. افتح موقعك
  3. اذهب إلى: Site Settings → Build & Deploy
  4. اضغط على: "Clear cache and retry deploy"
  5. انتظر 2-3 دقائق

إذا كنت تستخدم Vercel:
  1. اذهب إلى: https://vercel.com/dashboard
  2. افتح موقعك
  3. اذهب إلى: Project Settings → General
  4. اضغط على: "Clear Cache"
  5. ثم اذهب إلى: Deployments
  6. اضغط على: "Redeploy"

إذا كنت تستخدم Cloudflare:
  1. اذهب إلى: https://dash.cloudflare.com
  2. اختر الدومين hisas1.com
  3. اذهب إلى: Caching → Configuration
  4. اضغط على: "Purge Everything"
  5. انتظر دقيقة


الخطوة 2️⃣: أعد نشر الموقع
━━━━━━━━━━━━━━━━━━━━━━━━━

في Netlify:
  1. اذهب إلى: Deploys
  2. اضغط على: "Trigger deploy"
  3. اضغط على: "Deploy site"

في Vercel:
  1. اذهب إلى: Deployments
  2. اضغط على آخر deployment
  3. اضغط على: "Redeploy"


الخطوة 3️⃣: امسح كاش المتصفح
━━━━━━━━━━━━━━━━━━━━━━━━━━━

Windows/Linux:
  1. اضغط: Ctrl + Shift + Delete
  2. اختر: "Last hour" أو "Last 24 hours"
  3. حدد: ✅ Cached images and files
  4. حدد: ✅ Cookies and site data
  5. اضغط: Clear data

Mac:
  1. اضغط: Command + Shift + Delete
  2. اختر: "Last hour"
  3. حدد: ✅ Cached images and files
  4. اضغط: Clear data

ثم افتح الموقع في Incognito:
  • Chrome: Ctrl + Shift + N (Windows) أو Command + Shift + N (Mac)
  • Firefox: Ctrl + Shift + P
  • Safari: Command + Shift + N

ثم افتح: https://hisas1.com

🔧 إذا لم يعمل الحل السريع
═══════════════════════════════════════════════════════════════════

المشكلة قد تكون في DNS:
━━━━━━━━━━━━━━━━━━━━━━━━

1. تحقق من DNS:
   → اذهب إلى: https://dnschecker.org
   → أدخل: hisas1.com
   → اختر: A أو CNAME
   → اضغط: Search

2. إذا كانت النتائج مختلطة (✅❌):
   → DNS لم ينتشر بعد
   → انتظر 24-48 ساعة
   → استخدم رابط Netlify/Vercel المباشر مؤقتاً

3. تحقق من إعدادات الدومين:
   في لوحة تحكم الدومين (GoDaddy/Namecheap/etc):

   إذا كنت تستخدم Netlify:
     Type: CNAME
     Name: @ (أو www)
     Value: your-site-name.netlify.app
     TTL: Automatic

   إذا كنت تستخدم Vercel:
     Type: CNAME
     Name: @ (أو www)
     Value: cname.vercel-dns.com
     TTL: Automatic
