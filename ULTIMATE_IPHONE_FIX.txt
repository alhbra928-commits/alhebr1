🚨 الحل الجذري المطبق:

بدلاً من محاولة إصلاح position:fixed على Safari،
تم تطبيق نهج جديد كلياً:

1️⃣ تثبيت body نفسه على iPhone:
   body.is-iphone {
     position: fixed;
     overflow: hidden;
     height: calc(var(--vh) * 100);
   }

2️⃣ جعل #root قابل للتمرير:
   body.is-iphone #root {
     position: relative;
     overflow-y: auto;
     height: calc(var(--vh) * 100);
   }

3️⃣ الشريط في wrapper بارتفاع كامل:
   .unified-dock-wrapper {
     position: fixed;
     top: 0;
     height: calc(var(--vh) * 100);
     display: flex;
     align-items: center;
   }

────────────────────────────────────────────────────────────────

💡 الفكرة الأساسية:

بدلاً من:
  body (scrolls) → dock (tries to stay fixed)

أصبح:
  body (fixed) → #root (scrolls) → dock (truly fixed)

النتيجة:
  الشريط ثابت تماماً لأن body نفسه ثابت!

────────────────────────────────────────────────────────────────

✅ المميزات:

1. CSS Variable للـ viewport:
   --vh يتم حسابه ديناميكياً
   = window.innerHeight * 0.01

2. Body Class ديناميكي:
   document.body.classList.add('is-iphone')
   التطبيق فقط على iPhone

3. GPU Layer:
   transform: translateZ(0)
   backface-visibility: hidden
   will-change: transform

4. Pointer Events:
   wrapper: pointer-events: none
   content: pointer-events: auto
   الأزرار قابلة للنقر

5. Contain:
   contain: layout style paint
   عزل كامل عن باقي الصفحة
