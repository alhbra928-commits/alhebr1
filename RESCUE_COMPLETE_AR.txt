✅ المرحلة 3: Auto-Fill القاطع
═══════════════════════════════════

نظام تكرار ذكي يمنع الفراغ نهائياً:

(أ) JSX البسيط:
    <div className="marquee-mask">
      <div className="marquee-track" ref={trackRef}>
        <div className="marquee-group" ref={groupRef}>
          {activityCards}
        </div>
      </div>
    </div>

(ب) JavaScript Auto-Fill:
    1. احسب عرض المجموعة (groupWidth)
    2. احسب عرض الشاشة (maskWidth)
    3. خزّن عرض المجموعة في CSS: --group-w
    4. كرر المجموعة حتى نغطي 3× عرض الشاشة
    5. كل نسخة تحمل data-clone="1"

(ج) CSS Animation الدقيق:
    @keyframes marquee {
      from { transform: translate3d(0, 0, 0); }
      to { transform: translate3d(calc(-1 * var(--group-w)), 0, 0); }
    }

    → يتحرك بالضبط بمقدار عرض مجموعة واحدة
    → لا -50% تقريبي!
