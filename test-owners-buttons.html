🧪 اختبار أزرار أصحاب المزارع

اختبار شامل لجميع الأزرار والإجراءات في بطاقة صاحب المزرعة

📊 معلومات الاتصال

جاري الاتصال بقاعدة البيانات...

🎯 الأزرار الرئيسية (الصف الأول)

1️⃣ زر "عرض"

✅ يعرض تفاصيل المالك + قائمة مزارعه

2️⃣ زر "تعديل"

✅ يفتح نموذج تعديل البيانات (يظهر مع الصلاحية)

⚡ الإجراءات السريعة (الصف الثاني)

3️⃣ زر "تجميد/تفعيل"

✅ يبدل حالة الحساب (active ↔ frozen)

4️⃣ زر "اتصال"

✅ اتصال هاتفي مباشر

5️⃣ زر "حذف"

✅ حذف نهائي مع نسخة احتياطية JSON

🚀 الإجراءات الموسعة (الصف الثالث)

6️⃣ زر "المزيد"

✅ يُظهر/يُخفي الإجراءات الإضافية

7️⃣ زر "واتساب"

✅ إرسال رسالة WhatsApp مباشرة

8️⃣ زر "المالية"

✅ عرض المعاملات المالية

9️⃣ زر "مزرعة"

✅ إضافة مزرعة جديدة
