🔄 الآلية الجديدة للحذف

1. المستخدم: ينقر على زر "حذف" في بطاقة التوثيق
2. النظام: يعرض رسالة تأكيد مفصلة
3. عند التأكيد: يتم استدعاء DocumentationService.deletePermanently()
4. Service Layer: يستدعي RPC function في قاعدة البيانات
5. Database Function:
  • ✓ يتحقق من وجود السجل
  • ✓ يحذف السجل بـ SECURITY DEFINER
  • ✓ يسجل في audit_log (إن وُجد)
  • ✓ يُرجع نتيجة JSON
6. Frontend:
  • ✓ يحدث القوائم المحلية
  • ✓ يعيد تحميل البيانات
  • ✓ يعرض رسالة نجاح مفصلة

💻 الكود الجديد

Database Function:

CREATE OR REPLACE FUNCTION delete_documentation_permanently( p_documentation_id uuid, p_reason text DEFAULT 'حذف من لوحة التحكم' ) RETURNS jsonb SECURITY DEFINER -- ⭐ المفتاح: يتجاوز RLS SET search_path = public LANGUAGE plpgsql AS $$ DECLARE v_doc_record record; v_result jsonb; BEGIN -- التحقق من وجود السجل SELECT * INTO v_doc_record FROM documentation WHERE id = p_documentation_id; IF NOT FOUND THEN RAISE EXCEPTION 'شهادة التوثيق غير موجودة'; END IF; -- تسجيل في audit_log (إن وُجد) BEGIN INSERT INTO audit_log (...) VALUES (...); EXCEPTION WHEN undefined_table THEN NULL; -- تجاهل إذا لم يكن موجوداً END; -- حذف السجل فعلياً ⭐ DELETE FROM documentation WHERE id = p_documentation_id; -- إرجاع النتيجة RETURN jsonb_build_object( 'success', true, 'deleted_id', p_documentation_id, 'certificate_code', v_doc_record.certificate_code, 'message', 'تم حذف الشهادة بنجاح' ); END; $$;

Frontend Service:

static async deletePermanently(id: string, reason: string) { console.log('🗑️ [DELETE] بدء عملية حذف شهادة:', id); try { const { data, error } = await supabase .rpc('delete_documentation_permanently', { p_documentation_id: id, p_reason: reason }); if (error) { console.error('❌ [DELETE ERROR]:', error); // رسائل خطأ واضحة let userMessage = 'فشل حذف الشهادة'; if (error.message.includes('غير موجودة')) { userMessage = 'الشهادة غير موجودة أو تم حذفها مسبقاً'; } throw new Error(userMessage); } console.log('✅ [DELETE SUCCESS]!'); return data; } catch (err) { console.error('❌ [DELETE EXCEPTION]:', err); throw err; } }

🧪 كيفية الاختبار

خطوات الاختبار:

  1. افتح صفحة إدارة التوثيق

    انتقل إلى قسم "التوثيق" في لوحة التحكم

  2. اختر شهادة للحذف

    انقر على زر "حذف" في أي بطاقة توثيق

  3. أكّد الحذف

    ستظهر رسالة تأكيد - اضغط "موافق"

  4. افتح Console

    اضغط F12 وراقب الرسائل:

    🗑️ [DELETE] بدء عملية حذف شهادة: [UUID] 🗑️ [DELETE] السبب: حذف شهادة... ✅ [DELETE SUCCESS] تم حذف الشهادة بنجاح! ✅ [DELETE SUCCESS] البيانات المرجعة: {...}
  5. تحقق من النتيجة

    ✅ الشهادة يجب أن تختفي من القائمة فوراً
    ✅ رسالة نجاح مفصلة تظهر
    ✅ البيانات تُحدّث تلقائياً
