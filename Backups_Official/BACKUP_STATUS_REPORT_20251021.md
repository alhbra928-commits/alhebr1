## 🔄 نظام النسخ الاحتياطي الآلي

### الحالة الحالية: ⚠️ نصف آلي

**الوضع الحالي:**
- ✅ جدول `backup_history` موجود في قاعدة البيانات
- ✅ دوال النسخ الاحتياطي جاهزة
- ✅ سياسات الأمان مفعلة
- ⚠️ لا يوجد جدولة زمنية (cron)
- ⚠️ النسخ يتم يدوياً عند التطوير

### التوصيات للتفعيل الكامل:

#### الخيار 1: استخدام Supabase Functions (موصى به)
```typescript
// Edge Function تعمل كل يوم عند منتصف الليل
Deno.cron("daily-backup", "0 0 * * *", async () => {
  const { data, error } = await supabase.rpc('create_full_backup', {
    p_backup_name: `auto_backup_${new Date().toISOString().split('T')[0]}`,
    p_backup_type: 'automatic'
  });
});
```

#### الخيار 2: استخدام pg_cron (مباشر في PostgreSQL)
```sql
-- تفعيل الإضافة
CREATE EXTENSION IF NOT EXISTS pg_cron;

-- جدولة نسخة احتياطية يومية
SELECT cron.schedule(
  'daily-automatic-backup',
  '0 0 * * *',
  $$SELECT create_full_backup('auto_daily_backup', 'automatic')$$
);
```

#### الخيار 3: GitHub Actions (للنسخ الخارجية)
```yaml
name: Daily Backup
on:
  schedule:
    - cron: '0 0 * * *'
jobs:
  backup:
    runs-on: ubuntu-latest
    steps:
      - name: Create backup
        run: tar -czf backup_$(date +%Y%m%d).tar.gz ...
```
