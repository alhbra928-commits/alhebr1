📋 التعديلات المطبقة:
--------------------

1. ملف جديد: src/lib/iosViewportLock.ts
   • lockIOSViewport() - قفل الـ viewport
   • preventIOSBounce() - منع scroll bouncing

2. تحديث: src/main.tsx
   • استدعاء lockIOSViewport()
   • استدعاء preventIOSBounce()

3. تحديث: src/index.css
   • .appShell: height: var(--app-vh, 100svh)
   • body: overscroll-behavior: contain
   • .appMain: overscroll-behavior: contain


🔬 كيف يعمل الحل:
----------------

1. Visual Viewport API تقرأ الارتفاع الحقيقي للشاشة
2. يتم حفظ القيمة في CSS variable: --app-vh
3. جميع العناصر تستخدم --app-vh بدلاً من 100vh
4. عند تغير الـ viewport، نحدّث القيمة فوراً
5. النتيجة: لا قفز على الإطلاق!

🧪 كيفية الاختبار:

   1. افتح Safari Developer Tools

   3. يجب أن تظهر قيمة (مثل: 844px)
